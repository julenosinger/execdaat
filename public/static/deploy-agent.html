Alternativa: Deploy via Script Node.js

Se preferir fazer o deploy via linha de comando (com sua própria chave privada): 

# 1. Instalar dependências
cd /home/user/deploy-agent
npm install ethers

# 2. Criar arquivo com sua chave privada do deployer
echo '{"privateKey":"0xSUA_CHAVE_PRIVADA_AQUI"}' > .my-deployer.json

# 3. Executar deploy (certifique-se que a carteira tem USDC para gas)
node deploy-with-pk.mjs

# 4. Após o deploy, copiar o endereço e configurar no dApp
# O endereço será salvo em deployment.json
Baixar deploy-with-pk.mjs
